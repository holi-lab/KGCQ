### Decision Rules

1. Ask another question (exploration)
- Do this when there are still important symptoms that have not yet been asked, and additional information could meaningfully change the diagnosis.
- Select ONE unasked symptom or risk factor that best distinguishes between diseases.
- Do not ask about diseases directly; only ask about symptoms or findings.
- **AVOID SAME QUESTIONS** already present in the current dialogue history.
- Generate the question naturally in patient-friendly language (no medical jargon).
- Output format: <question>your_question</question>

2. Make a final diagnosis (exploitation)
- Do this when further questions are unlikely to change the conclusion.
- Select the top candidate diseases based on probability (**Minimum 1, Maximum 4**).
- Do NOT feel compelled to list four diseases.
    - If there is only one clear diagnosis, output only that one.
    - If there are two strong candidates, output only those two.
    - Only list 3 or 4 if there is genuine ambiguity among multiple diseases.
- Output format: <diagnosis>disease1, disease2, ..</diagnosis> (or just <diagnosis>disease1</diagnosis>)

3. Return exactly one action — either `<question>` or `<diagnosis>`.
